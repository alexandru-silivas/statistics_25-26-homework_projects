Simulating Brownian Motion with the Euler–Maruyama Method

In this assignment, we revisit the stochastic differential equation (SDE) simulator introduced in previous work and adapt it to the fundamental continuous-time random process in probability theory: Wiener process (standard Brownian motion).

The goal is to simulate Brownian motion over a time interval \( T \), using the Euler–Maruyama numerical scheme for stochastic differential equations:

\( dX_t = \mu(X_t,t)\,dt + \sigma(X_t,t)\,dW_t \)

For standard Brownian motion, the drift and diffusion functions simplify to:

\[ dW_t = 0 \cdot dt + 1 \cdot dW_t \quad\text{so the update rule becomes}\quad W_{t+\Delta t} = W_t + \sqrt{\Delta t}\,Z, \]

where \( Z \sim \mathcal{N}(0,1) \) is a standard normal random variable, typically generated via Box–Muller transform.

1. Theoretical Background

A Wiener process \( (W_t)_{t \ge 0} \) is characterized by:

  • \( W_0 = 0 \)
  • Independent increments
  • Gaussian increments: \( W_{t+h} - W_t \sim \mathcal{N}(0,h) \)
  • Almost surely continuous paths

Brownian motion is the continuous-time limit of a symmetric random walk and is foundational for:

  • stochastic calculus (Itô integrals)
  • financial modelling (Black–Scholes)
  • diffusion processes and physics
  • simulation of general SDEs

2. Euler–Maruyama for Brownian Motion

Using \( n \) uniform subintervals of size \( \Delta t = T/n \), we approximate:

\( W_{t_{k+1}} = W_{t_k} + \sqrt{\Delta t}\,Z_k \), \quad \( Z_k \sim \mathcal{N}(0,1). \)

This gives a discrete sampling of Brownian motion whose distribution converges to true Wiener process behaviour as \( n \to \infty \).

4. Optional Extension: General SDE Simulator

Because the Euler–Maruyama scheme already supports generic drift and diffusion terms, extending this tool to a full SDE simulator only requires the user to specify functions \( \mu(x,t) \) and \( \sigma(x,t) \). The JavaScript code is written so this generalization can be enabled with minimal extra work. 

X_{t+Δt} = X_t + μ(X_t,t) Δt + σ(X_t,t) √Δt Z

Setting \( \mu = 0 \) and \( \sigma = 1 \) reproduces Brownian motion.

This makes the simulator flexible enough to handle Ornstein–Uhlenbeck processes, geometric Brownian motion, or any sufficiently regular SDE.
